# Did I lose it here, or there?

A last-seen object finder for low-resource settings. A phone on a stand takes a photo of a room every 30 seconds. When you ask where an object is, it says which of 8 zones the object was last seen in, and when.

This repository holds our project write-up as a website. Open `index.html`, or visit the GitHub Pages link for this repository.

**Team:** Christiana Adisa, Safia Gibril, Khethiwe Dlamini and Alaa Almouiz Farog Mohammed, AIMS, November 2026.

## What is in this folder

- `index.html`: the blog post, with the results and the demo.
- `video.mp4`, `poster.jpg`: our video showing how the app should work.
- `room.jpg`, `keys.png`: photos used in the post.
- `f/`: the 60 Session 2 test photos used in the demo. People are blurred.
- `reg/`: examples of our registration photos.

## Notes

- Voice questions in the demo use the browser's speech recognition. They work in Chrome and Edge and need an internet connection. Spoken answers use the browser's own voice.
- The demo answers come from our placement log, using the same last-seen rule as the system. They show what the system should say.
- People in the photos are blurred, and so are the certificates in the glass cabinet.
